# 용돈박스 결합상품 분석 도구 명세 (5단계)

경쟁 상품 CSV를 읽어 가격 통계와 결합유형 분포를 텍스트 리포트로 보여 주는 작은 분석 도구를 완성한다. 최종 흐름은 다음과 같다.

```
CSV 텍스트 → [1 행 검증] → [2 파일 파싱] → [3 가격 통계] ─┐
                                              └→ [4 결합유형 집계] ─┴→ [5 리포트]
```

이미 `schema.py`, `parse_file.py`, `stats.py`(아직 구현 안 됨), 예시 `sample.csv`, `test_smoke.py`가 있다. 아래 5단계를 **번호 순서대로** 구현한다.

공통 규칙
- Python 3 표준 라이브러리만 쓴다.
- 금액은 원 단위 정수다.
- 한 단계는 아래에 적힌 파일 하나만 바꾸거나 만든다.
- 기존 `test_smoke.py`는 계속 통과해야 한다.
- 한 행은 `dict`이며 키는 `name`, `price`, `combo_type`, `review_count`다. (`schema.FIELDS`)

---

## 1단계 — `schema.py`: 행 검증

`validate_row(raw)`는 CSV에서 읽은 문자열 `dict` 하나를 검증해, 타입이 맞는 `dict`를 돌려준다. 잘못되면 `ValueError`.

- `name`: 앞뒤 공백을 지운 뒤 비어 있으면 `ValueError`.
- `price`: 앞뒤 공백과 쉼표(`,`)를 지우고 정수로 바꾼다. 정수가 아니거나 0 이하이면 `ValueError`. 예: `"12,900"` → `12900`.
- `combo_type`: 앞뒤 공백을 지운 뒤 비어 있으면 `ValueError`.
- `review_count`: 앞뒤 공백을 지운 뒤 비어 있으면 `0`. 아니면 정수로 바꾸고, 정수가 아니거나 음수이면 `ValueError`.
- 키가 없거나 값이 `None`이면 빈 문자열로 본다.
- 반환: `{"name": str, "price": int, "combo_type": str, "review_count": int}`

## 2단계 — `parse_file.py`: CSV 파싱

`parse_csv(text)`는 CSV 전체 문자열을 받아 `(rows, errors)`를 돌려준다.

- 맨 앞의 BOM(`"﻿"`)은 지운다.
- 첫 줄은 헤더다. 헤더 이름은 앞뒤 공백을 지우고 비교한다. 네 필드 중 하나라도 없으면 `ValueError`(빈 문자열도 마찬가지). 컬럼 순서는 상관없고, 모르는 컬럼은 무시한다.
- 따옴표로 감싼 값 안의 쉼표를 올바르게 처리한다(`csv` 모듈을 써도 된다).
- 완전히 빈 줄은 건너뛴다.
- 각 데이터 줄은 1단계 `validate_row`로 검증한다. 성공하면 `rows`에, `ValueError`가 나거나 컬럼 수가 헤더와 다르면 `errors`에 `(줄번호, 메시지)`를 넣는다. 줄번호는 파일 줄 번호이고 헤더가 1이다(빈 줄도 번호를 차지한다).
- 오류가 있어도 나머지 줄은 계속 처리한다. `rows`와 `errors`는 파일 순서를 지킨다.

## 3단계 — `stats.py`: 가격 통계

`price_stats(rows)`는 `rows`(2단계 결과)의 `price`로 `dict`를 돌려준다.

| 키 | 값 |
|---|---|
| `count` | 행 수 |
| `min`, `max` | 최소, 최대 |
| `mean` | 평균. 원 미만은 버린다(내림). |
| `median` | 중앙값. 짝수 개면 가운데 두 값의 합을 2로 나눈 몫(내림). |

- `rows`가 비어 있으면 `{"count": 0, "min": None, "max": None, "mean": None, "median": None}`.

`price_histogram(rows, bin_size)`는 가격을 `bin_size` 단위 구간으로 센다.

- 구간 시작값은 `(가격 // bin_size) * bin_size`.
- `(시작값, 개수)` 튜플 목록을 시작값 오름차순으로 돌려주되, 가장 작은 구간부터 가장 큰 구간까지 **개수가 0인 구간도 포함**한다.
- `bin_size`가 0 이하이면 `ValueError`. `rows`가 비어 있으면 `[]`.

## 4단계 — `crosstab.py`(새 파일): 결합유형 집계

`combo_counts(rows)`는 `combo_type`별 개수를 `(결합유형, 개수)` 목록으로 돌려준다. 개수 내림차순, 같으면 결합유형 이름 오름차순.

`combo_by_price_band(rows, bands)`는 결합유형 × 가격대 표를 `{결합유형: {라벨: 개수}}` 딕셔너리로 돌려준다.

- `bands`는 가격대 상한 목록이다(예: `[10000, 20000]`). 비어 있거나 정수가 아니거나 엄격한 오름차순이 아니면 `ValueError`.
- 라벨: 첫 구간 `"~10000"`, 중간 구간 `"10001~20000"`, 마지막 구간 `"20001~"`. 가격이 상한 **이하**면 그 구간이다.
- 각 결합유형 딕셔너리에는 모든 라벨이 들어간다(없으면 0).

## 5단계 — `report.py`(새 파일): 텍스트 리포트

`build_report(rows, errors)`는 3·4단계 결과를 이어 붙인 문자열을 돌려준다. 줄은 `"\n"`으로 잇고, 맨 끝에 줄바꿈은 붙이지 않는다. 숫자는 천 단위 쉼표를 넣는다.

`sample.csv`를 읽은 결과의 예:

```
분석 대상 5건, 오류 0건
가격 최소 9,900원 / 최대 39,000원 / 평균 21,240원 / 중앙값 19,900원
결합유형별 상품 수
- 단독: 2
- 화장품: 2
- 건강식품: 1
```

오류가 있으면 맨 끝에 `오류 줄: 4, 7` 같은 줄이 붙는다.

- 1줄: `분석 대상 {행 수}건, 오류 {errors 개수}건`
- 2·3줄과 결합유형 줄들은 행이 1개 이상일 때만 나온다. 결합유형 줄은 `combo_counts` 순서다.
- `errors`가 비어 있지 않으면 마지막에 `오류 줄: ` 뒤에 줄번호를 `", "`로 이어 붙인다.
- 행이 없고 오류도 없으면 1줄만 나온다.
