# "다음 단계" 확인 박스 관찰 (앱 UI, 응답 끝의 버튼 달린 질문 카드)

박스는 실험 설계에 없던 요소다. 회마다 턴별로 뜬 여부를 기록한다. 박스 버튼은 누르지 않고 정해진 문장을 직접 입력한다. 승인 창(허용/거부)과는 다르다.
| 회 | 턴1 | 턴2 | 턴3 | 턴4 | 턴5 |
|---|---|---|---|---|---|
| A1 | 있음 | 있음 | 있음 | 있음 | 없음 |
| B1 | 있음 | 있음 | 있음 | 있음 | 없음 |
| B2 | 있음 | 있음 | 있음 | 있음 | 없음 |
| A2 | 있음 | 있음 | 있음 | 있음 | 없음 |
| A3 | 있음 | 있음 | 있음 | 있음 | 없음 |
| B3 | 있음 | 있음 | 있음 | 있음 | 없음 |
